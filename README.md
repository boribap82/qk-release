# QK 수량산출 — 릴리스

엑셀 추가기능 **QK**의 배포 저장소입니다. 설치 파일과 업데이트 정보만 들어 있습니다.

- `setup/QK_v<판>_setup.zip` — 설치 꾸러미(설치·제거 실행기, 로더, 본체, 팀 라이브러리, 설치 안내)
- `latest.json` — 최신 판 번호와 파일별 sha256. 엑셀 안의 QK가 하루 한 번 이 파일을 읽어 업데이트를 알립니다.
- `releases/v<판>/` — 판별 본체 파일과 변경내역
- `library/<판>/` — 팀 라이브러리(라이브러리만 바뀐 패치는 이 파일만 받습니다)
- `docs/설치안내.md` — 설치·업데이트·이전 버전으로·제거 방법

## 설치 요약

1. 엑셀을 모두 닫습니다.
2. `setup/` 에서 최신 `QK_v<판>_setup.zip` 을 받아 압축을 풉니다.
3. `QK_Setup.bat` 을 두 번 누릅니다.
4. 엑셀을 켜면 리본에 **수량산출** 탭이 보입니다.

제거는 같은 폴더의 `QK_Uninstall.bat` 입니다. 사용자 라이브러리는 남습니다.

업데이트는 로그인 없이 이 저장소의 공개 주소로만 받습니다. 받은 파일은 sha256 을 확인한 뒤 씁니다.
