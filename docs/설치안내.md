# QK 수량산출 설치 안내 (한 장)

## 설치
1. **엑셀을 모두 닫습니다.** 엑셀이 켜져 있으면 설치기는 아무것도 바꾸지 않고 멈춥니다.
2. 인터넷 주소 `github.com/boribap82/qk-release` 의 `setup` 폴더에서 최신 `QK_v<판>_setup.zip` 을 받습니다.
3. 받은 zip 을 오른쪽 단추 → **압축 풀기** 합니다(zip 안에서 바로 실행하지 않습니다).
4. 풀린 폴더의 **QK_Setup.bat** 을 두 번 누릅니다. «설치 끝» 이 보이면 아무 키나 누릅니다.
5. 엑셀을 켜면 리본에 **수량산출** 탭이 보입니다. 매크로 경고 없이 열립니다.

설치 자리: `%APPDATA%\QK\` (현재 사용자만). 관리자 권한은 필요 없습니다.

## 업데이트
- 엑셀을 켜고 몇 초 뒤, 하루 한 번 새 판을 확인합니다. 새 판이 있으면 «새 버전 vX (지금 vY) … 업데이트할까요?» 를 묻습니다. 올린 새 판은 몇 분 뒤부터 보입니다.
- **예** 를 누르면 받은 파일의 sha256 을 확인하고 저장합니다. **엑셀을 다시 켜면** 새 판이 열립니다.
- 라이브러리만 바뀐 패치는 바로 적용됩니다(엑셀을 다시 켜지 않아도 됩니다).
- 지금 확인: 리본 **수량산출 → 도움말 → 업데이트 확인**.
- 끄기: 리본 **자동 업데이트 확인** 을 풉니다.
- 인터넷이 안 되면 조용히 넘어가며, 엑셀 시작을 막지 않습니다.

## 이전 버전으로
리본 **도움말 → 이전 버전으로** 에서 설치된 판을 고르면, 다음에 엑셀을 켤 때 그 판이 열립니다. 옛 판 폴더는 지우지 않습니다. 옛 판으로 계속 쓰려면 **자동 업데이트 확인** 을 풉니다(켜 두면 다음 날 새 판을 다시 묻습니다).

## 옛 양식 산출서
옛 판으로 만든 산출서를 열면 새 양식으로 맞출지 묻습니다. **예** 면 같은 폴더에 `…_갱신v<판>.xlsx` 복사본을 만들어 갱신하고, 원본은 그대로 둡니다.

## 제거
1. 엑셀을 모두 닫습니다.
2. 설치 때 풀었던 폴더의 **QK_Uninstall.bat** 을 두 번 누릅니다.
3. 엑셀 추가기능 등록과 신뢰할 수 있는 위치를 지우고 프로그램 파일을 지웁니다. **사용자 라이브러리**(`%APPDATA%\QK\library\user`)는 남깁니다.

## 안 될 때
- **리본에 탭이 없다**: 엑셀 → 파일 → 옵션 → 추가 기능 → 아래 «관리: Excel 추가 기능» → 이동 → `QK` 가 체크되어 있는지 봅니다.
- **매크로가 차단되었다는 붉은 띠**: 설치를 다시 실행합니다(받은 파일의 차단 표시를 풉니다).
- **업데이트 확인이 늘 «서버에 닿지 않음»**: 회사 망에서 `raw.githubusercontent.com` 이 막혀 있을 수 있습니다. 새 판은 설치 꾸러미를 다시 받아 설치해도 됩니다(옛 판은 남습니다).
